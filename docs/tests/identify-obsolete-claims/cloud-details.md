## Cheap cloud models

All cloud runs were executed with the reasoning effort set to `medium`.

The table view lists the models that passed the test, along with their IDs, total task execution costs, total completion tokens, and request counts, sorted by cost in ascending order.

The **"Output"** column provides an indication of the number of reasoning tokens generated by each model.

Each request involves reprocessing previous interactions as input for the new interaction. This is billed as cache, unless not available.
